Cocoa Window Level Hierarchy

Standard floating utility windows use NSFloatingWindowLevel (level 3), which causes them to hide behind native macOS Full Screen Spaces. QOTA binds directly to NSScreenSaverWindowLevel (level 1001) to remain tactile and persistent across every virtual desktop.
