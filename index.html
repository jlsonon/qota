FREQUENTLY ASKED QUESTIONS

Everything you need to know.

Clear answers on architecture, privacy, compatibility, and local telemetry.

What is QOTA?

A zero-cloud desktop HUD and menu bar pill tracking real-time AI sprint and weekly rate limits across Antigravity, Claude Code, and Codex.

How does QOTA track quotas without cloud relays?

Reads local session files and SQLite WAL databases directly on your drive. Zero API keys required; zero bytes leave your machine.

What is Cocoa Level 1001?

Level 1001 (NSScreenSaverWindowLevel) pins the HUD above full-screen IDEs and spaces without stealing window focus or keystrokes.

Which AI models and multipliers are supported?

Antigravity (Flash 1x), OpenAI Codex (o3-mini 2x), and Claude Code (Sonnet 4x, Opus 8x) with automatic proportional accounting.

Is QOTA free and open source?

Yes. 100% free and open-source software under the permissive MIT License on GitHub.

Does QOTA work on Windows and Linux?

Yes! Native System Tray for Windows 10/11 with WS_EX_TOPMOST, plus Linux and Android overlay support.
